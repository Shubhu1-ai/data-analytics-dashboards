# Data Analytics Dashboards

A collection of dashboard projects built to practice turning raw data into decision-ready business insights, using Power BI and Tableau.

## Projects

### 🤖 [Robotics Adoption & Industry Impact](./robotics-industry-impact) — Power BI
Analyzes how robotics adoption has affected productivity, cost, and the workforce across manufacturing, healthcare, and logistics (2015–2023).

### 📦 [Logistics & Supply Chain Analysis](./logistics-supply-chain-analysis) — Tableau
Analyzes global sales, shipping efficiency, and payment methods across international markets.

Each project folder has its own README with full details, data files, and key insights.
